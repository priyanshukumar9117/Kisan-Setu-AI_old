# Audio Controls Feature Guide - Kisan_Sarthi Chatbot

## Overview
Every AI response in the chatbot now includes interactive audio controls for a rich, user-friendly experience.

## Audio Control Features

### 1. **Play/Pause Button** ▶ / ⏸
- Click to start playing the AI's response audio
- Click again to pause
- The button shows a pulse animation while audio is playing
- Only one audio can play at a time (previously playing audio will pause automatically)

### 2. **Progress Bar**
- Visual representation of audio playback progress
- Shows current position with a draggable indicator
- Click anywhere on the bar to jump to that position
- Real-time update as audio plays

### 3. **Time Display**
- Shows `Current / Total` duration in MM:SS format
- Example: `1:23 / 2:45`
- Updates in real-time during playback

### 4. **Volume Control** 🔊
- Slider ranging from 0 (mute) to 100 (full volume)
- Default volume: 100%
- Smooth volume adjustment while playing

### 5. **Playback Speed Control**
- Four preset speeds: **0.75x**, **1x** (default), **1.25x**, **1.5x**
- Click any button to change playback speed
- Active button is highlighted
- Useful for listening faster or slower based on preference

### 6. **Download Button** ⬇
- Click to download the audio file locally
- File name format: `kisan_audio_[timestamp].mp3`
- Save for offline listening or sharing

## How to Use

### Basic Playback
1. Look for an AI response with audio controls below it
2. Click the **▶** (Play) button
3. Audio will start playing
4. Button changes to **⏸** (Pause)
5. Click **⏸** to pause, or click again to resume

### Seek/Skip
1. Click anywhere on the progress bar to jump to that position
2. Or wait for the progress fill to reach your desired position

### Adjust Volume
1. Move the volume slider (🔊) left to decrease, right to increase
2. Slide all the way left to mute

### Change Speed
1. Click one of the speed buttons: **0.75x**, **1x**, **1.25x**, **1.5x**
2. Audio will immediately play at the new speed
3. Active button is shown with highlight

### Download Audio
1. Click the **⬇** (Download) button
2. Audio file will be saved to your device with timestamp
3. Use for offline access or sharing

## Technical Details

### Supported Audio Formats
- MP3 (primary format from google TTS)
- WAV (from local TTS)
- Any format supported by HTML5 Audio element

### Language Support
- English (en)
- Hindi (hi)
- Bhojpuri (bho)

### Browser Compatibility
- All modern browsers (Chrome, Firefox, Safari, Edge)
- Mobile browsers supported
- Responsive design for all screen sizes

## Keyboard Shortcuts
- **Space** (when focused on play button): Toggle play/pause
- **Enter** (in chat input): Send message

## Troubleshooting

### Audio Won't Play
- Ensure volume is not muted in browser
- Check internet connection (if using cloud TTS)
- Try refreshing the page
- Check browser console for errors

### Audio Quality Issues
- Try a different playback speed
- Check system volume is appropriate
- Adjust browser volume in system settings

### Audio Not Downloading
- Ensure browser allows downloads
- Check if download location has sufficient space
- Try a different browser if issue persists

## API Integration
The audio URLs are generated by the backend API at initialization:
- Endpoint: `/query/`
- Response includes: `audio_url` field when audio is generated
- Backend uses either Google TTS or local pyttsx3 based on settings

## Persistence
- Chat history with audio URLs stored in browser localStorage
- Audio URLs are saved and restored when reopening chat
- Clear Chat button removes all history and audio references
